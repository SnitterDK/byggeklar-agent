# Demo script (under 5 minutes)

1. **Problem and audience** — homeowners and small construction professionals
   lose time assembling incomplete permit material.
2. **Run the sample** — carport, Copenhagen, measurements present, drawings
   attached, site plan and verified local-plan reference missing.
3. **Show real work** — the agent classifies the case, checks every required
   fact and produces owner and municipality action queues.
4. **Resolve evidence** — attach the site plan and local-plan reference, rerun,
   and show the review-ready evidence pack.
5. **Architecture** — show Strands Agent calling the deterministic permit-pack
   tool; explain why the safety gate remains authoritative.
6. **Integrity** — state that the municipality makes the decision and no
   approval or impact metric is invented.
